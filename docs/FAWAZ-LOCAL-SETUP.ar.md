# إعداد OpenMontage على جهاز آخر

هذا الدليل ينقل خطوات الإعداد؛ ملفات الوسائط والحسابات وبيئة Python تحتاج تجهيزًا على كل جهاز.

1. افتح هذا المستودع على فرع التحديث أو نسخة دمجه.
2. اقرأ AGENTS.md ثم AGENT_GUIDE.md وQuick Start في README.md.
3. جهز Python وNode.js وFFmpeg واعتماديات requirements.txt واعتماديات remotion-composer وفق README وملف القفل. أنشئ .venv على الجهاز الجديد؛ لا تنسخ بيئة جهاز آخر.
4. سجل الدخول إلى Claude Code بحسابك، ثم افتحه داخل جذر المستودع واعتمد المجلد.
5. شغّل scripts/fawaz-doctor.py باستخدام Python الخاص ببيئتك. في Windows يمكن استخدام scripts\\fawaz-python.cmd scripts/fawaz-doctor.py.
6. من /mcp اعتمد الخادم الذي تحتاجه، ثم Authenticate إن احتاج تسجيل دخول. وجود .mcp.json لا ينقل رموز الدخول.
7. شغّل tests/tools/test_fawaz_mux_duration.py باستخدام Python الخاص بالبيئة لفحص حدود دمج الصوت والحفاظ على الأصل.
8. استعد أصول مشروعك من مصدره المعتمد؛ projects/ وملفات الفيديو لا تنتقل بمجرد نسخ Git.
9. scripts/fawaz-verify-compose.py اختبار تشخيصي لمدخل محلي موجود. يحتاج ملف المدخلات وأصوله ومساراته الصحيحة؛ لا يدّعي هذا المستودع توزيع وسائط المستخدم أو نتائج حساباته.
10. اتبع pipeline المشروع ومهارات كل مرحلة للإنتاج. اختبر خدمة محددة قبل الدفعات؛ اكتشاف مهارة أو محرك لا يثبت نجاح التوليد.

## طلب جاهز لكلود
اقرأ AGENTS.md وAGENT_GUIDE.md وهذا الدليل. افحص المحركات بواسطة scripts/fawaz-doctor.py، وفرّق بين المهارات والمحركات والموصلات. استخدم الحسابات الموجودة أولًا. لا تفترض أن الأصول أو المصادقة انتقلت من الجهاز السابق. اختبر عينة محلية واحفظ أدلتها محليًا دون رفع سجلات الحسابات أو الوسائط إلى المستودع العام.

## نطاق الإصلاح
مسار Windows يشغّل Remotion CLI المثبت مباشرة، ويسجل stdout في ملف لتجنب تعليق الأنابيب. دمج الصوت محدود بمدة الفيديو الأصلية، مع مهلة تنفيذ، ويحتفظ بالأصل عند الفشل.
