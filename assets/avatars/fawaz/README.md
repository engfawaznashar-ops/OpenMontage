# أفاتار فواز — المرجع المعتمد

هذا المجلد هو **مرجع الهوية** لشخصية فواز الكرتونية. أي طلب فيه «استخدم الأفاتار حقي» أو «خلّ الأفاتار يقول…» أو مشهد يظهر فيه فواز كرتونيًا، يبدأ من هنا:

1. خذ `primary/fawaz-avatar-primary.png` كمرجع أساسي دائمًا.
2. أضف مرجع التعبير الأقرب من `expressions/` (مثلًا `fawaz-thinking.png` لمشهد تفكير).
3. للزوايا الجانبية أو الخلفية أضف ورقة الدوران من `turnaround/`.
4. ولّد الصورة أو اللقطة الجديدة بتعابير وملامح وحركة مختلفة، مع الحفاظ على أقفال الهوية أدناه.

التوليد يمر عبر مهارة `higgsfield-unlimited` (المشمول في الاشتراك، بدون كريدت). ولا تُرسم الشخصية ولا تُحرَّك بالكود (SVG/Remotion/Blender). الكود للنص والكابشن والتجميع فقط. ملفات `vector/` للتصميم الثابت والطباعة، لا للتحريك.

## أقفال الهوية (لا تتغير بين اللقطات)

- وجه دائري ممتلئ، بشرة برتقالية دافئة، ظل لحية خفيف حول الفم والذقن.
- عينان كبيرتان بنيّتان، حواجب سوداء كثيفة معبّرة، أنف كبير مدوّر.
- شماغ/غترة بيضاء مع عقال أسود، ثوب أبيض بياقة وجيب صدر، نعال سوداء.
- أسلوب كرتون مسطّح بخط أسود عريض وظلال زرقاء فاتحة على الأبيض.

## المحتويات

| المجلد | الملفات | الاستخدام |
|---|---|---|
| `primary/` | الأساسي (ذراعين متقاطعين)، الوقفة المحايدة، لقطة قريبة | مرجع الهوية الرئيسي لكل توليد |
| `expressions/` | 11 تعبيرًا: anxious, confident, excited, happy, inspired, playful, sad, serious, shocked, surprised, thinking + ورقة تعابير بعناوين عربية | مرجع التعبير المطلوب |
| `turnaround/` | ورقتا دوران (أمام، ثلاثة أرباع، جانب، ميل الرأس) | الزوايا غير الأمامية |
| `vector/` | نسخ SVG للتعابير + أوراق دوران (ثوب، بيجامة، قميص أزرق) | تصميم ثابت، طباعة، أغلفة |
| `styles/` | البحر المتوسط، المحقق، الإماراتي (+ لوح بيئة الغرفة) | ستايلات المسلسلات القائمة فقط |

البيانات نفسها بصيغة آلية في `avatar.json`.
